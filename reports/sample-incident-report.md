# Incident Reports

This directory contains scenario-based incident reports created during the lab.

| Report | Description |
|---|---|
| `scenario-01-port-scan-report.md` | Port scanning detection and investigation |
| `scenario-02-brute-force-report.md` | SSH brute force detection and investigation |
| `scenario-03-05-post-exploitation-chain-report.md` | PowerShell, Registry persistence, and privilege escalation attack chain |
| `incident-response-report-post-exploitation-chain.pdf` | Final formatted incident response report |

Each report documents the detection source, evidence, analyst conclusion, and response notes where applicable.
