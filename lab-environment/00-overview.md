### Lab overview

This main objectif of this Lab is simulate Real-production enironments incidents detection (receiving logs -> Match rules -> Correlate events -> Generate Alerts -> to generate alerts and visualize them in Dashboard visualization), but that after or during applicate common attacks scenarios: (Simulate port scanning, Perform brute force attacks (SSH / RDP), Execute PowerShell payloads, Modify registry keys for persistence), then make a strong Incident Response like a high-skilled SOC Analyst (Alert → Triage → Investigation → Validation → Report) 

## Components
  - Windows 10 Pro (Agent)
  - Windows Server Datacenter 2022 (Active Directory)
  - Ubuntu Server (SIEM)
  - Kali (Attacker)
