# Modern SOC Pipeline Lab

## Overview
This project is a Security Operations Center (SOC) simulation lab designed to replicate a real-world security monitoring and incident detection environment.

The goal is to understand how attacks are detected, analyzed, and responded to using industry-standard security tools and workflows.

---

## Objective

The main objectives of this project are:

- Build a realistic SOC environment using virtual machines
- Simulate cyber attacks in a controlled lab
- Collect and analyze security logs
- Detect malicious activities using SIEM rules
- Understand the full incident lifecycle from attack to response
